# Primeiros Experimentos Web

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-B99000?style=flat-square&logo=javascript&logoColor=white)

Exercício introdutório de HTML, CSS e JavaScript, com caixas de diálogo, leitura de uma resposta e alteração da página conforme uma condição.

## Conteúdo

O código está em [`site para meu amor`](site%20para%20meu%20amor), um arquivo HTML que foi salvo sem extensão.

## Como visualizar

Baixe o arquivo, salve uma cópia local com extensão `.html` e abra essa cópia no navegador.

## Competências praticadas

Estrutura HTML, estilos, `alert`, `confirm`, `prompt` e condicionais. Este repositório registra uma etapa inicial do aprendizado.

Para estudos posteriores, visite [JavaScript](https://github.com/Kleber720/JavaScript) e [HTML e CSS](https://github.com/Kleber720/html).
